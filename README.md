# CERO Escalada 

## Cambios
- Las cuatro fotografías de clases son las seleccionadas en la conversación: panorámica para Principiantes, hombre con arnés para Adultos, dos personas en el muro para Entrenamiento y niño con pantalón verde para Infantil.
- Los retratos verticales se ajustaron sin recortar a los escaladores y sin duplicar imágenes.
- Contacto: nuevo título «¿Listo para tu primera escalada?» y texto más directo.
- Se mantienen los colores y todos los enlaces de V7, incluido el acceso a Google Maps.

## Para abrir
Abrir `index.html` con los archivos `styles.css`, `script.js` y `assets` en la misma carpeta.

## Formulario
Utiliza FormSubmit. El titular de ceroescalada@gmail.com debe confirmar la activación y verificar un envío real antes de publicar.

## Publicar en GitHub Pages
Subir el contenido de la carpeta a la raíz del repositorio y activar Settings > Pages > Deploy from a branch > main / (root).

**Confirmar los horarios de las clases antes de usar la página públicamente.**
